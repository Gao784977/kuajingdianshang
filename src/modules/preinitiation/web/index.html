A. 基础输入

展示当前 S1 支持的字段。带 * 为当前正算路径必填； 未知请留空（缺失成本不会自动补 0）。这是流程验证输入，不是完整 OP 输入集。 售价与目标利润率互斥，只能填写其中之一。

B. 手工候选

手工录入降级路径：来源固定 manual，准入状态固定为「准入未验证」（≠ 已满足 1688 准入）。 搜索/摘要报价仅展示；有效采购价只取 SKU 级价格。一期报价币种仅 CNY，其他币种会被拒绝（不静默换算）。

新增手工候选
SKU 与阶梯价

C. 演示测算

演示测算使用 TestOnlyProvider 固定测试输出，不随输入计算真实利润，且允许展示负利润率。 真实计算入口当前不可用（公式未通过验证）。

有未保存修改：测算基于已保存内容，而非当前表单

D. 快照与事件

快照内容不可变（生成后不受后续输入影响）；输入/参数/候选变化后，旧快照仅标记为历史（过期）， 内容与事件历史不变。过期快照禁止新的确认操作。正式确认当前不可用，可查看门禁原因。

要求：最新复算为 ok、基于有效采购价、且未过期。

E. 导出「待核验预览单」

导出内容为待核验预览单（非正式测算）：JSON 强制包含 preview_notice / demo / mode / verification / snapshot_versions / expired；文件名与页面均标注「禁止用于审批或采购决策」。浏览器下载不等于已提交审批。
