## 3. S1 实施摘要（安全受限本地验证；**S2 已移植入仓，见 §3A**）

- **位置（S1 阶段）**：/workspace/preinitiation/（独立最小模块）。**当时未放入旧项目**：旧项目 v3.2 Web 运行层缺失（backend/storage 未提交）不可运行（01 §2.1），且与其 Excel 研究管道无共享模块；纯 Python 标准库，无新框架、无独立登录。**S2 起正式位置为仓库内 `repo-kuajingdianshang/src/modules/preinitiation/`（本轮授权"优先复用现有项目结构和入口"），本节以下描述以仓库内模块为准。**
- **已实现**：输入校验与双版本管理、结果依赖记录与失效判断、手工候选及有效采购价校验、决策快照内容生成（frozen+事件）、模拟确认（幂等）与正式确认门禁（七项，当前必拒）、内存 Repository（保证范围 docstring 声明）、可执行示例（`python3 -m preinitiation.example`）、自动化测试 31 项全通过（`python3 -m unittest discover -s preinitiation/tests -t .`）。

## 3A. S2 实施摘要（仓库内纵向切片，2026-10-15 本轮）

- **位置**：`repo-kuajingdianshang/src/modules/preinitiation/`（11 个源文件 + web 静态资源）+ `tests/` 下 10 个测试文件与 1 个辅助器。S1 独立目录的模块/测试移植入仓，导入路径适配，**断言未放宽**。
- **本轮新增行为**（对应授权第五、六部分）：
  - **六类版本体系**：input_version / meta_version / params_version / sourcing_version 之外新增 **calc_version**（计算结果版本）与 **snapshot_seq**（快照序列版本），不混用单一 status 字段；
