## 3. X-Owner-Id：冒用实测与表述修正

- **实测（新增 `TestHttpImpersonation`，HTTP 层）**：`X-Owner-Id` 完全客户端自报、可任意冒用——仅凭该头即可读 `/api/state`、即可从 `/api/session` 领取对应工作区写令牌。
- **修正**：`workspace.py` / `webapp.py` / `__init__.py` 文档串及 06/07 文档中"隔离"表述全部改为**"owner 数据分区（键空间分区，非安全隔离）"**；测试文件 `test_preinitiation_isolation.py` 更名 `test_preinitiation_partition.py`（9→10 项）。
- **生产化契约**（已写入文档）：owner 必须来自宿主系统验证后的用户上下文，不得信任客户端自报头。本地单用户演示语义不受影响。

## 4. 演示门禁：服务端强制验证（新增 `test_preinitiation_gate_tamper.py`，6/6 通过）

- 篡改 `mode` / `verification` / `approved_for_decision` / `test_only` 等字段**不可提级**——服务端按自身状态重建，不信任请求声明；
- `real-confirm` 对演示结果**必拒**；`real` 计算返回 blocked + 原因清单、**不输出任何数值**；
- 导出标识（水印/test_only/approved_for_decision=false）由**服务端强制写入**，客户端无法去除；
- 未知字段拒绝（`unknown_field`）；HTTP 层无审批/转产品路由（NOT_IMPLEMENTED）；
- 模块零网络调用（静态核查：仅标准库、无外部请求）。
